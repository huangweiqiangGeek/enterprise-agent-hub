## 实现决定

- 会话 Cookie 为 host-only、HttpOnly、SameSite=Lax，生产配置 Secure；不使用 localStorage 保存凭据。登录会话固定七天，匿名 CSRF 会话三十分钟，过期后重新认证。
- 为 AP01 匿名 CSRF，auth_sessions.user_id 允许空；随机会话与 CSRF 原值分别置于 HttpOnly Cookie，数据库只存哈希。AP01 仅在 Cookie 匹配有效记录时返回对应 CSRF。注册/登录撤销旧会话并轮换两枚 Cookie。
- 所有变更请求校验精确 Origin 允许列表和绑定会话的 X-CSRF-Token。密码变更撤销全部会话；组织操作每次从数据库取当前成员与角色，组织锁串行化成员及 owner 变更。
- owner 始终由 organizations.owner_user_id 推导；延迟复合外键确保提交时该账号仍是成员。角色变更与移除递增 access_revision；成员编辑使用自身 revision，转移使用 accessRevision 作为 expectedRevision。
- 创建组织、添加成员、转移所有权保存请求摘要及响应；重复键重放前验证当前权限。组织创建在账号锁内串行化；其他写入在组织锁内完成。
- 页面使用已有深绿 #24584d、正文 #183a36、米白 #f5f5ee、边线 #cbd8d1、错误 #a52a32、白色 #ffffff。中文使用系统无衬线字体；桌面左导航右内容，移动端折叠为顶部导航，表单左对齐。避免无效的后续业务入口；提供明确的未开放说明。
- 采用现有 Vue/CSS 完成基础页，不在 D02 引入尚无实际消费者的 UI 组件库。敏感字段不持久保存，组织切换清除旧数据并中止请求。
