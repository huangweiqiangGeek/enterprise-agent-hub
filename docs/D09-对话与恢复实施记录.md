# D09 对话、SSE 恢复、来源与导出

2026-11-09。范围止于文档问答闭环，未实施 D10 取消/硬恢复、D11 统计或 T2/T3 执行。

## 使用与实现

登录后进入组织的“对话工作台”，或从已启用的问答 Agent 进入。选择知识库、按需限定文档并填写问题；资料尚未就绪时给出准备提示。已接受任务显示持久 run，刷新、断网或换页不创建新任务。会话可搜索、分页、重命名；同会话保持固定 Agent/任务类型，追问明确选择资料范围。

结果区区分生成中草稿与校验后的答案，事实、推断、建议和资料不足有文字标签。点击引用查看实际文档、处理版本、片段、位置、摘录与观察时间。步骤按需分页，只展示公开摘要和按服务区分的计量。成功结果可复制/下载 Markdown；非成功只能复制带未完成标记的部分文本。`/o/:orgId/runs/:runId` 是只读详情，管理员审计没有输入、停止或代发入口。

- 后端复用 RunService，新增 DialogueService 的授权读取投影。AP48/50/51/52/55/60 与 task-options、OpenAPI/生成类型同步；没有新增第三方依赖。
- `0008_conversations` 只增加 revision（默认1）和组织/owner/更新时间索引。乐观版本检查防止标题覆盖，迁移保留已有会话。
- 原键和原请求在 POST 前保存；响应未知用 AP61 核对，absent 后继续使用相同键。服务端事务/唯一运行约束仍是最终保证。
- SSE 短事务逐批鉴权，每批最多100条；空闲1秒轮询、15秒心跳。游标错误在响应头发出前返回 JSON，流中撤权关闭连接。
- 前端正确处理 UTF-8、CR/LF、分片、多行 data、注释与空行；只推进连续 seq，重复不追加、缺口重读同 run 快照，最终快照替换草稿。未知类型/版本不能标成功。
- 来源匹配 run，删除仅返回 tombstone；导出重新鉴权并完整包含范围、时间/UTC、文档版本、来源和覆盖限制，动态内容转义。
- 现有 API client 统一管理普通请求、流和下载；组织切换/注销/撤权使旧响应失效。权限检查5秒、隐藏页暂停、重新聚焦立即检查。
