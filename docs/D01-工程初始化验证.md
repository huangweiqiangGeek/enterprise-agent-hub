## 兼容调整

1. 宿主原有 Node 为 22.23.4、Python 为 3.15.2。项目分别锁 24.22.2/3.12.16；pnpm 自动选择项目 Node，uv 管理独立 Python 环境，不修改其他项目的默认 Node。
2. pnpm 12 不再使用旧的 onlyBuiltDependencies 配置方式，改用 allowBuilds；一般配置移入 pnpm-workspace.yaml。旧锁中短发布时间的 Vue 3.5.45 与 Nuxt 的 3.5.44 重复，统一 3.5.44 后重新生成本任务创建的锁文件，没有放宽全局策略。
3. OpenAI SDK 3 的 HTTP 客户端为 httpx2；MCP v1 使用 httpx。两者在独立协议边界共存，fixture 分别使用对应客户端。
4. MCP fixture 使用显式 localhost 端口匹配 SDK Host 校验，保留保护机制；并切换至未弃用的客户端函数。
5. checkpoint 连接只设置 `search_path=checkpoints`，不回退到 public。初始化前检查 Alembic head 与两个 schema，健康检查同时核对适配器四张表与迁移版本。
