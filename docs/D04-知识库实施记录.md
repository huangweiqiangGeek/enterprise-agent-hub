## 需求与方案

CP1：用户授权按 PRD M2-01/02/03/09 与 development-plan D04 实施；D02 身份、组织锁、幂等及 D03 模型/限额源码已核实。D03 真实提供方尚未验证，不妨碍文件接受的隔离验证；接受前必须有已通过能力测试的 Embedding 配置以固化版本，主体验库未配置时明确提示，不植入假模型。

PR-1：AP21～27、AP29、AP30 original、AP61 属本阶段；AP28 重试与 AP30 提取文本属于 D05，不提前实现解析/切片/Embedding worker。现有 S3+boto3、PostgreSQL outbox 方案能覆盖可靠接受，采用它而非增加本地文件业务存储。知识库/文档删除是接受后撤回所需最小能力，派生数据清理随后续消费者扩展。

CP2：流式读取 multipart，实际字节大小、单个 file 字段、扩展名/MIME/签名与 UTF-8 文本校验，受限临时文件计算完整摘要。短事务预检查→事务外 S3 put→组织锁内复核身份/权限/限额/模型→文档/attempt/outbox/幂等同事务→202；网络和文件传输不占身份/组织锁。响应丢失先 AP61 核对，absent 仅允许原键相同内容重发。模型与组织限制固化到接受快照；后续解析完成前仅 queued。

PR-2～7 / ReviewGradeCard：全面/R3。冻结权限、复合外键、同键并发与异内容冲突、S3 成功 DB 失败、撤权/模型/限额接受竞态、文件大小边界、原文件鉴权代理和删除不可见。消费者为后端/数据库、Nuxt/API 类型、存储、outbox 与后续 D05；不扩展整个 Agent 系统。采用现有 CSS/组件与 XHR 单文件进度；不增加 UI 库。

CP3：按三批串行实施：①表/DTO/S3/流校验/知识库服务；②路由、outbox 基础、页面/契约；③隔离 PG+本地 S3+Redis、浏览器与主环境迁移、文档/Profile/报告。新增 boto3，python-multipart 升为直接依赖；存储最终使用 SeaweedFS 4.52 固定摘要开发 profile。实际存储服务验收与本地协议验收分开。

## 官方依据

- [boto3 配置](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/configuration.html)：Config、签名、有限网络超时与重试；同步调用进入有界线程池。
- [S3 PutObject](https://boto3.amazonaws.com/v1/documentation/api/latest/reference/services/s3/client/put_object.html)：可 seek Body、ContentLength、IfNoneMatch；对象成功不等于数据库事务提交。
- [python-multipart](https://multipart.fastapiexpert.com/)：MultipartParser 分块 write 与 part/header/data 回调；由业务限制实际读入量。
- [SeaweedFS 4.52 README](https://github.com/seaweedfs/seaweedfs/blob/4.52/README.md)、[mini 配置源](https://github.com/seaweedfs/seaweedfs/blob/4.52/weed/command/mini.go)：mini -dir、AWS 凭据环境变量、S3 8333、持久卷；关闭 WebDAV/Admin UI，仅宿主 loopback 4566 映射 S3。Docker Hub 返回 4.52 摘要 sha256:57877e32bb90073b37dc109b438ba66e84fd5ed9ced5f5c04f56444ef243ce59，实际拉取一致。
- [Celery 调用](https://docs.celeryq.dev/en/stable/userguide/calling.html)：按名称 send_task、指定 task_id 和 retry；outbox 决定退避，消费者仍需按 attempt 幂等。

实际锁定版本：boto3/botocore 1.43.125、s3transfer 0.19.3、jmespath 1.1.0、python-multipart 0.0.33；Nuxt/Node/Python/SQLAlchemy 与既有锁保持兼容。初选 LocalStack 4.14.0 虽读写通过，重启验收出现 NoSuchBucket，故弃用；其旧卷保留但不再挂载。MinIO 官方社区仓库已停止维护且官方 Docker Hub 标签不可取得，未安装；S3Mock 文档不保证跨重启数据复用，未采用。最终以 SeaweedFS 的实际重启/重建读回作为本地持久化证据。
