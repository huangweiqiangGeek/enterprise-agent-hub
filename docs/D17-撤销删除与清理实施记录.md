# D17 撤销、删除与清理实施记录

日期：2026-11-14。基于 D16 `75f8bd0`，无新数据库迁移。本文区分工程验证、受控模型/MCP、真实外部依赖和部署。

## 实现

- 复用现有组织锁、当前成员权限、accessRevision、调用前后与终态交付检查。删除后原文/检索不可访问，历史答案保留且来源为墓碑；GitHub 当前授权失效仍隐藏混合回答、步骤、来源及导出。
- 知识库详情按路由隔离；预览、检索结果、详情请求随组织/权限版本同步失效，迟到响应不可恢复。原文件下载纳入 API 请求代际取消边界，不再裸 fetch 绕过身份失效。
- API 普通请求、下载和上传收到 401 均清会话/组织/Nuxt 缓存并取消其他请求；一般资源 403 不误清整个组织。GitHub 凭据与仓库草稿在权限变化时清除，失权不被离开确认阻挡。
- `Lifecycle` 按批清理终态超过 7 天且无有效 lease 的 SSE events/checkpoint（legacy thread 和 g1..g3；恢复 generation 上限仍为 3）、过期/撤销超过 7 天的 session、超过 30 天的数据库 audit。保留 run.lastSeq、messages、citations、steps、usage、幂等键和业务运行记录；旧事件游标仍走 EVENT_CURSOR_EXPIRED 后读取快照，不创建新运行。
- 失败/取消超过 24 小时的 attempt 派生正文/向量/S3 对象由 outbox 清理，保留 attempt 元数据和墓碑。候选查询和执行前均排除活跃 run 快照/来源引用及有效 lease。活跃文档清理延后 60 秒，不消耗失败重试次数。
- 孤儿扫描仍限专属前缀、对象超过 24 小时、每页 100 条并查数据库反向引用；额外保护尚未发布但仍持 lease 的派生对象。不会按文件名推断可删除。
- 文档容量已有 1000 上限；新增历史 run 10000 上限，受组织锁保护，已接受同幂等键仍可恢复。片段 50000 上限在模型调用前预检及事务发布再次检查。部署容量只可调低，不删除历史来腾容量。错误/环境变量以 [contracts](contracts.md) 为准。
- QA 意外中断新增安全 run_id/exception_type 日志，未打印正文、凭据或完整异常。仅提升可诊断性，未宣称修复此前偶发 RUN_INTERRUPTED。

## 维护与部署边界

`dispatcher` 每小时启动一轮维护，run 游标非空时每 5 秒续一批，每类最多 100 条。输出 `requestId`、扫描/清理计数、`runCleanupFailed`、`cleanupExhausted`；失败 checkpoint 不继续删对应 events，后续轮次重试。outbox 现有五次有界重试及显式失败重试继续适用。

手动维护前必须核实目标数据库/桶、备份与保留政策。下列命令会实际删除满足保留期的数据，不是预览：

```powershell
# 先显式选择正确 EAH_DATABASE_URL 与 EAH_S3_*，不要直接对体验库执行。
.venv/Scripts/python.exe -m scripts.maintenance --apply --limit 100
# 输出 nextCursor 非空时，用该值继续下一批。
.venv/Scripts/python.exe -m scripts.maintenance --apply --limit 100 --cursor <nextCursor>
# 修复外部存储等原因后，显式恢复已耗尽的 outbox 重试（最多100条）。
.venv/Scripts/python.exe -m backend.workers.outbox --retry-failed
```

不带 `--apply` 的维护命令拒绝执行。删除后失效立即生效，不以后台清理成功为授权条件；恢复存储故障不会恢复用户访问。外部日志平台/容器日志的 30 天轮转和外部告警路由需部署配置，本次只提供安全 stdout 诊断/失败计数，不声称已经接通外部告警或清理外部日志。用户已经看到或下载的内容不能远程擦除。

本次所有破坏性测试只在自动创建并回收的 PostgreSQL 数据库/S3 测试桶执行；未对主体验库运行维护命令、迁移或重启部署服务。
