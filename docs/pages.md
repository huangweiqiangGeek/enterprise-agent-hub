## 信息架构与通用布局

```text
顶部：组织选择 | 当前组织/角色 | 账号菜单
左侧：工作台 / 知识库 / Agent / 对话与任务 / 连接与工具 / 执行记录 / 团队与设置
主体：当前页标题、说明、主操作、筛选、内容
右侧按需打开：来源原文 / 步骤详情；窄屏改用抽屉
```

默认中文，问题和文档可中英混合；回答跟随问题语言。界面展示用户目的、资料与结果；模型 checkpoint、租约、内部表名等实现细节放维护文档，不能混入普通任务表单。readOnly、资料不足、覆盖不完整、Token 估算等直接影响判断的信息必须显示。

首版桌面优先；≥1280px 可三栏，768～1279px 合并侧栏，<768px 导航与来源采用抽屉。移动端允许完成核心操作，不增加独立移动产品。布局断点是实现默认，不是 PRD 新功能。

## 通用状态与组件职责

| 组件/规则 | 职责与交互 | 验收 |
| --- | --- | --- |
| OrganizationSwitcher | 切换时 abort 旧请求/订阅、清旧组织缓存，再加载新组织；不取消后台 run | 加载时不闪现旧组织内容；404/403 不回退旧数据冒充成功 |
| ResourceReadiness | 展示模型、Agent、文档、GitHub 缺失条件；操作入口按角色分配 | 成员看到“联系管理员”；无需 GitHub 的模板不被 GitHub 缺失阻止 |
| FieldError/FormDirtyGuard | 标签、必填、字段错误、未保存离开提示；服务端字段错误映射 | 错误聚焦第一个无效字段，输入保留；敏感字段不存 localStorage |
| AsyncAction | idle/submitting/accepted/uncertain/error；每次提交固定幂等键直到结果确定 | 双击、超时、重发不生成第二任务；uncertain 先 AP61 |
| StatusBadge | 直接映射 contracts，不把 cancelRequested 当终态 | 正在停止/已取消、传输完成/可检索清楚区分 |
| SourceDrawer | 按当前权限获取来源，显示版本/定位/观察时间 | 不使用失效缓存；返回删除/撤销时清正文并显示原因 |
| SafeMarkdown | 原始 HTML 禁用，链接协议过滤，代码块普通展示 | 脚本、javascript 链接不可执行；外链可识别 |
| ListState | loading、初次空态、筛选空态、加载错误、分页结束分别处理 | 请求失败不显示零条/零用量；重试只读 |

查询状态由 Nuxt composable 按组织/资源/过滤条件缓存，页面草稿是本地状态；API 类型从 OpenAPI 生成。首版不加重复全局状态库；跨页身份/组织仅保存必要状态。SSR 转发 Cookie 只到固定同源 API，不把凭据写入公开 runtimeConfig。

## 登录、组织引导与账号

登录表单含邮箱、密码与进入按钮；注册另加显示名。密码可临时显示/隐藏，默认隐藏。无“忘记密码”“邮件邀请”“已验证邮箱”占位入口。AP01 取得当前会话与防伪令牌；AP02/AP03 提交后刷新身份。

登录成功 → 有组织则选择/进入最近仍有效的组织 → 无组织则显示“创建组织”或等待管理员添加；创建表单仅名称，AP08 接受后进入工作台准备状态。组织创建同键重发只一次。

账号页通过 AP05 修改显示名；AP06 修改密码需要当前密码，新密码再次输入在前端校验（确认值不传服务端）。成功后清除会话与业务内容，重新登录。退出用 AP04，失败说明未完成，不能仅在前端隐藏内容就宣称服务端已撤销。

验收：M7-01、M7-02、M7-09；登录失效后的重定向只接受站内路径，不跳任意外部 URL。非敏感草稿可在当前标签页内保留，密码和凭据不持久保存。

## M1 工作台

- 顶部三个任务卡片：文档问答、需求与方案对比、进展与风险总结。每张展示需要的资料与预期结果，点击进入 `/chat?taskType=...`，只预选模板，不创建 run。
- “最近会话”按本人更新时间展示标题、Agent、最近状态；点击原 conversationId。空态显示开始入口，失败态保留框架并可重试。
- “准备情况”列出三类模板各自缺失项；管理员可跳模型、知识库、Agent 或 GitHub 配置，普通成员显示可理解的求助说明。
- API：AP47、AP07、AP09、AP48。组织切换重取全部，不把缓存中的旧 ready 状态当调用保证。
- 验收：M1-01～M1-05；三个入口点击均无模型费用；没有 GitHub 时 T1/T2 仍能完成准备流程。

## M2 知识库

D04 已实现列表、页内新建/编辑表单、详情上传区和文档列表；文件详情展示接受元数据/尝试，可下载原文件和删除。D05 已实现提取文本、管理员片段预览与失败重试；列表每5秒更新状态，历史尝试保留，切换文档取消旧预览结果。D06 已加入管理员折叠检索试查，展示片段/定位/覆盖限制/用量，可限定当前页就绪文档，取消等待或切换组织时丢弃旧响应，同页删除清空试查结果。缺少已测试 Embedding 时明确链接模型配置；客户端校验只提前提示，最终权限和大小由后端接受事务裁决。

### 列表与详情

列表字段：名称、说明、文档总数、就绪/处理中/失败数、更新时间。管理员新建/编辑弹窗使用 AP22/AP23；名称去空格后必填、同组织唯一。知识库详情上方是说明和文件添加，下面按文件名/状态筛选并分页。

文档行：文件名、大小、上传时间、处理状态、尝试次数、操作。成员只查看；管理员重试/删除。相同文件名独立显示，通过时间和大小区分，不自动覆盖。

### 上传与处理

`选择/拖入 → 每文件格式/空文件/大小校验 → 独立进度 → AP26 接受 → queued/processing → ready/failed`。

使用支持 upload progress 的浏览器上传通道（XHR + 同源 Cookie/CSRF/组织头），逐文件可取消传输；不能为显示进度把“已发送字节”当作已入库。后端接受结果丢失则显示“正在核对上传结果”，用 AP61 查询并保持原键。若已被接受，提供删除入口撤回，不伪称 Abort 可以取消后台任务。

状态轮询只在存在 queued/processing 文档时进行，页面隐藏暂停，返回立即刷新；失败记录显示可行动原因。点击重试调用 AP28，新 attempt 独立记录，连点不重复建立 attempt。

### 预览、试查和删除

- 文档详情 AP27/AP30 展示当前版本提取文本；PDF 显示真实页码，TXT/MD 显示标题/段落。失败文件显示原因而非假正文。管理员折叠区 AP31 展示切片和定位。
- 管理员检索试查 AP32：输入查询 → 展示实际候选、文档、定位、排序分数与覆盖说明；没有结果和请求失败分别显示，不创建对话。
- 删除文档确认框说明新检索不可见、历史引用标删除；AP29 成功立即更新列表/选择器/打开的来源。清理异常只在管理视图可追踪，不恢复正文访问。
- 删除知识库 AP24 若存在当前 Agent 绑定，显示关联名称/链接；解除后用户再删除，不在后台自动解绑。
- API：AP21～AP32、AP61；验收：M2-01～M2-09。原文件下载经鉴权代理，不持有长期公开对象直链。

## M3 Agent 管理

列表展示名称、说明、固定任务类型、启用状态、当前版本和开始入口。成员只见已启用且可访问 Agent；管理员可筛停用。编辑页分“基本信息、提示词、知识范围、工具、模型”五组，不做拖拽工作流。

1. 从空白或模板创建：选择 taskType 后给对应默认 Prompt；保存前可修改。创建后类型固定，换类型新建 Agent。
2. AP35/AP36 保存生成不可变配置版本；可以保存不完整停用配置。启用 AP38 前展示 readiness 缺失项，相关字段可直接定位。
3. 复制 AP37：要求确认新名称，创建停用副本；失效资源引用剔除并提示需要重新配置。
4. 停用确认框说明新任务不可发起、在途下一检查点停止；不删除历史。试运行跳到 M4，明确“使用已保存的第 N 版配置，会计入用量”。未保存表单不能假装已生效。
5. 离开脏表单提示保留编辑或放弃；409 不覆盖，显示“配置已被更新”并允许重载后重新应用修改。

API：AP33～AP38、AP16、AP21、AP45；验收：M3-01～M3-07。停止 Agent 与停止某个 run 是不同操作，文案需区分。

D07已实现列表、新建与`/o/:orgId/agents/:agentId`配置页；模板及只读工具选项来自管理员`GET /agents/options`，AP45组织工具开关待D13。SSR表单在客户端完成交互绑定前禁用，保存时锁定输入；保存失败保留内容，冲突可显式重载。缺项链接只定位字段，不重置编辑状态。复制必须输入名称并提示复核副本范围。M3-07当前仅显示已保存版和未来计入用量的说明，试运行按钮禁用；真实跳转/运行等待D08/D09。M3-06当前验证启停资格、成员不可见和accessRevision，在途停止待D08/D10验证。

## M4 对话与任务

### 任务表单

| 类型 | 输入与默认值 | 提交前反馈 |
| --- | --- | --- |
| T1 | Agent、知识库、多选文档（可不限制）、问题 | 必须有就绪资料与非空问题；选中资料须仍在 Agent 范围 |
| T2 | Agent、需求文档、方案文档、可选关注点 | 两份不同且 ready；相同/处理中在字段旁提示，输入保留 |
| T3 | Agent、一个允许仓库、起止日期、显示时区、知识库、可选重点 | 默认最近七个当地自然日；不得倒置/未来日期；缺 GitHub 或就绪计划资料阻止提交 |

开始前显示“本轮范围”摘要：资料/版本、仓库、区间/时区、使用 Agent 版本、相关上限。T3 明示“按区间内更新记录取样，状态为查询时快照”。首次先 AP49 创建空会话，再 AP53 创建 run，两个身份各自幂等；空会话并不代表已调用模型。

### 对话与结果

```text
会话列表（可折叠） | 任务标题、Agent/模板、每轮范围          | 来源抽屉
搜索/重命名       | 用户输入                              | 文档版本/页码
最近会话与状态     | 排队 → 取证 → 生成中 → 最终状态         | 原文片段
                  | 回答 / 对比表 / 进展与风险分组          | GitHub 状态/查询时间
                  | 引用、覆盖限制、查看执行、复制/导出     |
                  | 下一轮范围选择 + 输入 + 开始/停止       |
```

生成中显示工具状态和标为草稿的回答，不展示“已校验”或最终导出。只有 AP54 的 succeeded 快照使结果进入最终态：T1 段落+引用；T2 双侧证据的差异表；T3 进展/阻塞/风险/待核实/建议分组。建议与推断有文字标签，不能仅用颜色区分。

引用点击 AP52 按需载入；抽屉显示来源标题、真实定位、版本、摘录和观察时间。删除时显示 tombstone；仓库权限撤销时清空整个相关回答、草稿和步骤结果，保留运行元信息。外链与平台来源预览区分，外链可用性由 GitHub 自己判断。

### 停止、重连与重试

- 快速连点只保留一个提交键；结果未知时核对原请求，禁止自动换键发第二次。当前会话 activeRun 时禁再次发送，但可以编辑草稿或切其他会话。
- 停止 AP56 后先显示“正在停止”；失败可重试停止请求。直到服务端终态才显示已取消。页面关闭只中止订阅，不取消后台 run。
- AP55 断开时显示重连状态，按连续 seq 恢复；刷新先 AP50/AP51/AP54，再恢复原流。游标过期从快照恢复，不新建 run。旧草稿被最终快照替换，不重复追加。
- failed/cancelled/timed_out 可“使用当前配置重新执行”：预填旧输入，重新校验现有范围，创建带 retryOfRunId 的新 run；与旧记录互链。若配置已失效，定位准备问题，不隐藏换用其他 Agent。
- 终态后追问保持同 Agent/模板；要换类型或 Agent 就新建会话。扩大资料/仓库范围必须通过选择器，不从自然语言偷偷扩权。
- succeeded 可复制及 AP60 下载 Markdown；含范围、生成时间/时区、答案、来源与覆盖限制。非成功只可明确“复制部分文本”，自动附未完成标记，不能下载为正式报告。

会话用 AP48 搜索，AP50 重命名。每轮可跳 M6 查看同一 run；管理员审计结果无输入框、停止或代发入口。验收：M4-01～M4-10、T1/T2/T3 全部 AC、E2E-01～E2E-04。

## M5 连接与工具

固定 GitHub 卡片：名称、连接状态、上次测试时间、凭据是否已配置、启用状态。密码式输入仅供首次填写/替换，保存后清空；现有值不回填。测试按钮 AP41 验证候选，保存 AP40 服务端再次测试新凭据后原子生效。错误区分认证、范围、网络和限流，不能显示原始提供方响应。

工具表展示用途、输入摘要、只读标识、启停；固定工具定义不可编辑，不能新增服务器 URL/启动命令。停用 AP46 展示影响，再更新 readiness。成员只有可用工具/仓库概览，不能访问凭据表单。

API：AP39～AP46；验收：M5-01～M5-08、NFR-02。页面没有创建 Issue、评论、合并、推送、工作流触发按钮。

## M6 执行记录与用量

列表顶端为统计卡：运行数、成功/失败/取消/超时数、成功率、聊天 Token、执行耗时；筛选包括创建日期区间/时区、状态、Agent，管理员另有“我的 / 组织审计”。AP57/AP59 使用完全相同过滤，零终态的成功率显示“暂无”。

详情 AP54/AP58 展示输入范围、历史配置版本、排队/执行时长、终态、相关重试，以及按时间展开的模型/检索/工具/验证步骤。step 展开只有公开参数和结果摘要、来源、尝试序号、用量与失败原因；不展示隐藏思维链。

用量按 chat/embedding/rerank 区分；实际、保守估算、不可得明确标记，失败/取消尝试不漏记。列表 Token 默认聊天用量，展开查看其余服务；runId 为空的入库/连接测试保存在后台调用记录，不计入运行成功率，首版不新增准备工作账单页面。

错误提示有下一步动作：本人可返回对话改输入/重试；管理员审计仅查看。撤销来源的步骤/回答显示不可用，不用缓存补齐。验收：M6-01～M6-07、NFR-10～NFR-12。

D11已落地`/o/:orgId/runs`及`/runs/:runId`：侧栏“执行记录与用量”进入列表，提交筛选后同步刷新列表和统计，改变筛选回第一页。管理员默认仍为“我的运行”，可切换“组织审计（只读）”；历史Agent选项包含已停用项。日期为包含结束日的本地日历区间，页面同时显示IANA时区、UTC边界及查询时间。零分母显示“暂无”，三类模型用量单独呈现实测/估算/Token不可得/结果未知与计费单位。详情展开历史输入、配置和预算，步骤来源沿用鉴权抽屉；本人返回对话准备重试，他人审计不显示该入口。列表/统计分别读取，进行中结算差异提示刷新核对；窄屏仅表格横向滚动。

## M7 团队与设置

- 团队页 AP10：成员名、邮箱、角色、加入时间。添加先 AP11 精确核对账号，再 AP12 加为 member；不存在提示先注册。admin 不能通过表单授予 admin。
- owner 可 AP13 任免管理员，AP15 转移所有权；转移对话框显示目标与原 owner 将转 admin，二次确认。移除 AP14 明示其将失去组织历史/事件/下载权限；当前 owner 无直接移除入口。
- 模型页 AP16～AP18 分聊天、Embedding、Rerank。填写被支持的提供方、模型与凭据，最小调用测试前说明会计用量；保存展示生效配置与时间。成员只看可用名称。有存量文档或处理任务时 Embedding 模型/维度只读，说明需维护重建；更换同模型凭据仍可测试后保存。
- 限制页 AP19/AP20 展示系统硬上限和组织上限；管理员只能降低允许项目，前端与后端共同校验。说明变更只影响新接受任务，权限撤销仍立即生效。
- 账号入口按前文，组织切换及重新聚焦检查 AP09 的 accessRevision；被移除用户清理组织内容并退出该组织页。

## 页面级完成标准

每页至少验证初次加载、成功、空数据、请求失败、权限不足及与该页相关的提交中状态。上传补充单文件失败/接受结果未知；对话补充断线、取消竞争、终态恢复；配置补充版本冲突与撤销。

键盘可完成登录、模板选择、文件选择、发送、停止、打开/关闭来源；抽屉打开管理焦点，Esc 关闭后回到触发按钮；状态更新使用适当 aria-live，流式文字避免逐 token 打断读屏。表格在窄屏可滚动，关键操作不能只靠悬浮出现。

页面联调使用实际后端类型与错误码。mock 可用于组件状态验证，但不能证明鉴权、MCP 或引用已真实可用；D19 将页面操作映射到 PRD 的验收编号。


## D12 对比页面实现

M4对话工作台可选compare Agent，任务类型随固定Agent显示；提交前选不同的需求/方案就绪文档。追问和新重试需明确重新核对两侧资料；未确认的提交保存原键及双文档参数，断网核对不会换参重复执行。

RunView提供逐项对比表：需求/来源、方案证据/来源、覆盖状态、影响（待核对）、建议。未知不得渲染成零缺口或完整满足；覆盖区域与Markdown导出保留双侧文档版本、实际片段及裁剪限制。管理员审计仍为只读。
